# Haimabati Dey — Academic Research Homepage

A responsive, white-background academic homepage inspired by the editorial structure and information-rich presentation of SAJID Lab. This is an original static implementation, not a copy of that site's code or branding.

## Preview locally
Open `index.html` in a browser. It uses Google Fonts if internet access is available; system fallbacks are included.

## Publish using GitHub Pages
1. Create a public repository named **haimabati-dey.github.io** under your account `haimabati-dey` (or use any repository and configure Pages).
2. Upload the contents of this folder to the repository root. Make sure `index.html` is in the root.
3. Open repository **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. For a user-site repository, the URL will be `https://haimabati-dey.github.io/`.

## Editing content
Edit text directly in `index.html`. Layout, colors, responsive behavior and typography are in `assets/styles.css`; the JavaScript in `assets/main.js` is intentionally minimal. This site does not require Node, a framework, a build step, or a paid hosting service.

## Content and accuracy notes
- Profile and timeline information is adapted from the CV PDF supplied in this conversation.
- Selected research summaries are adapted from abstracts/project descriptions in the combined research PDF. Where full bibliographic information was not supplied, entries are presented as research documents/projects rather than claiming journal publication.
- The uploaded CV and research report PDFs are **not** included in this ZIP, so they will not be publicly exposed by accident.
- Please review contact, LinkedIn, and GitHub links before publishing. The LinkedIn URL is based on the handle provided in the CV and may need confirmation.
